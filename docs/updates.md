# dsh-user-sync 更新日志

> 面向使用者的更新记录（技术细节见仓库根目录 `CHANGELOG.md`）。
> 当前线上版本：**1.0.36**

## 1.0.36（2026-11-16）

**插件**

- 修复「从远端同步后，插件版本没有升上去」：同步时会回读已安装版本与远端声明版本比较，旧版本目录不再被误判为「已安装」；装不上时自动再跑一次 `pnpm install --force`，仍失败的插件会在结果里列出名字与原因。
- 本插件自身有新版本时只提示「下次重启生效」，不再自动重启 DSH（自动重启会打断正在进行的任务）。
- 需要重启时由你决定：插件提供手动重启接口，重启会等旧进程完全退出后再启动新实例。

## 1.0.35（2026-11-12）

**插件（客户端）**

- 同步应用后自动对齐插件：远端清单里有而本机缺的自动安装、版本落后的自动升级、已从远端移除的自动卸载；有变化时页面自动刷新一次即可生效，不需要重启 DSH。
- 上传/同步进行中会显示遮罩，阻止误点其他按钮；超过 60 秒后可手动关闭遮罩，操作仍在后台继续。
- 同步时净化 `pnpm-workspace.yaml`：只保留 `package.json` 里仍声明的包，已卸载插件的残留条目不再被带回本机。

**服务端（运营方）**

- 新增上传/下载次数统计：上传在写包成功时计数；下载只统计客户端触发的下载（后台下载不计）。
- `/v1/admin/packages` 支持分页（默认 50）与排序，插件统计拆分为 `/v1/admin/plugin-stats`（默认 100 条）。
- 新增 `GET /v1/admin/packages/:account/download`：把某账号的最新同步包下载为 zip。
- 新增 `DELETE /v1/admin/packages?account=<key>`：删除该账号的同步包，保留账号与历史统计。

## 1.0.34（2026-11-06）

- 修复：从远端同步 `~/.dsh/skills` 的技能时，文件会正确落到技能目录（之前落到了 `~/.dsh/dsh-skills`）。
- 「从远端同步」结果弹窗新增「强制覆盖」：本机有改动时也能强制拉取远端覆盖本机。
- 覆盖确认弹窗的时间改为本地格式显示。
## 1.0.33（2026-11-06）

- 技能同步范围新增 `~/.dsh/skills`：DSH 原生技能与 `~/.agents/skills` 会一起同步，同名技能以 `~/.dsh/skills` 为准。
- 「同步范围」里的技能数字改为技能个数（一个技能多个文件只算 1 个）。
## 1.0.32（2026-10-30）

- 插件详情页新增「同步状态」卡片（描述下方）：账号、版本、服务地址、上次检查与结论，一眼可见。
- 插件显示名与描述：设置同步 / User Sync（含「更新需重启 DSH」提示），并新增插件图标。
- 上传空包（0 个文件）现在会被拒绝，并提示「没有可同步的文件（请检查同步范围）」。
- 新增本地开发脚本：`python scripts/dev.py start|stop|status|restart`（一条命令起停本地服务）。

## 1.0.27

**新增：用户反馈**

- 插件面板「自动检查」卡片右侧新增「反馈」按钮，可提交设计建议 / 功能建议 / 问题 / 其他；
- 提交成功弹窗显示「提交成功 + 反馈编号」，失败弹窗显示原因（不再无提示）；
- 未提交内容自动存本地草稿，关掉面板再打开可恢复，提交成功后清空；
- 反馈会带上当前配对账号（前 6 位），方便定位。

**服务端（运营方）**

- 新增 `POST /v1/feedback`（匿名提交，按真实 IP 限流）；
- 新增运营方接口：反馈列表（含总数）、详情、统计（总数/按状态/按类型）、单条删除、按时间批量清理、处理状态（待处理/处理中/已完成/已拒绝 + 处理意见）。


**开发版**

- 开发安装（链接/junction）时，面板「服务地址」行右侧出现「切到本地 / 切到远程」按钮，可在本地服务端与远程服务端之间一键切换（正式安装不显示）。

## 1.0.26

**新增：运营方数据接口**

- `/v1/admin/packages`：各账号同步包列表 + 按模块分类汇总（技能/插件/配置/用户记忆）+ 全量插件使用统计；
- `/v1/admin/package`：单账号包详情与文件清单；
- `/v1/admin/package/file`：查看单个文件文本内容（配置 / 技能 / 用户记忆，不截断）。


## 1.0.25

- 插件独立性：插件启动时把自己写入 profile 的 `minimumReleaseAgeExclude`，避免本插件的新版本让其他插件被 pnpm 冷却期策略拦住（安装/卸载其他插件不受本插件影响）。

## 1.0.24

- 开发安装（junction/link）下点「更新插件」不再执行 pnpm add（会与链接冲突报错），改为提示「当前是开发安装（link），重启 DSH 即加载最新代码」。

## 1.0.23

- 上传/同步进行中两个按钮同时禁用，并按动作显示「上传中… / 同步中…」；
- 上传/检查/同步的结果统一用弹窗展示（成功与失败都有详情和「知道了」）。

## 1.0.22

- 修复内置插件页报 `loaded without registering ... via __ModuleLoader__.load`：客户端模块加载器缺失时显式报错，不再静默跳过注册。

## 1.0.21

- 状态卡调整：「服务地址」从页面底部移到「版本」下一行，只读展示（内置 / 自定义），底部不再重复。
