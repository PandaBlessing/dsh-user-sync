# dsh-user-sync 更新日志

> 面向使用者的更新记录（技术细节见仓库根目录 `CHANGELOG.md`）。
> 当前线上版本：**1.0.27**

## 1.0.27

**新增：用户反馈**

- 插件面板「自动检查」卡片右侧新增「反馈」按钮，可提交设计建议 / 功能建议 / 问题 / 其他；
- 提交成功弹窗显示「提交成功 + 反馈编号」，失败弹窗显示原因（不再无提示）；
- 未提交内容自动存本地草稿，关掉面板再打开可恢复，提交成功后清空；
- 反馈会带上当前配对账号（前 6 位），方便定位。

**服务端（运营方）**

- 新增 `POST /v1/feedback`（匿名提交，按真实 IP 限流）；
- 新增后台接口：反馈列表（含总数）、详情、统计（总数/按状态/按类型）、单条删除、按时间批量清理、处理状态（待处理/处理中/已完成/已拒绝 + 处理意见）。

**管理后台**

- 新增「用户反馈」页面：总数、各状态数量、按类型 Tab、按状态筛选、查看/处理/删除、按时间清理、导出 CSV；
- 首页新增「用户反馈」统计卡（切回首页自动刷新）。

**开发版**

- 开发安装（链接/junction）时，面板「服务地址」行右侧出现「切到本地 / 切到远程」按钮，可在本地服务端与远程服务端之间一键切换（正式安装不显示）。

## 1.0.26

**新增：运营方后台数据接口**

- `/v1/admin/packages`：各账号同步包列表 + 按模块分类汇总（技能/插件/配置/用户记忆）+ 全量插件使用统计；
- `/v1/admin/package`：单账号包详情与文件清单；
- `/v1/admin/package/file`：查看单个文件文本内容（配置 / 技能 / 用户记忆，不截断）。

**管理后台**

- 新增「同步包管理」页：账号包列表、模块汇总、文件清单、模块内容查看（config / userMemory 可直接看全文）；
- 新增「插件统计」页：各插件被多少账号使用。

## 1.0.25

- 插件独立性：插件启动时把自己写入 profile 的 `minimumReleaseAgeExclude`，避免本插件的新版本让其他插件被 pnpm 冷却期策略拦住（安装/卸载其他插件不受本插件影响）。

## 1.0.24

- 开发安装（junction/link）下点「更新插件」不再执行 pnpm add（会与链接冲突报错），改为提示「当前是开发安装（link），重启 DSH 即加载最新代码」。

## 1.0.23

- 上传/同步进行中两个按钮同时禁用，并按动作显示「上传中… / 同步中…」；
- 上传/检查/同步的结果统一用弹窗展示（成功与失败都有详情和「知道了」）。

## 1.0.22

- 修复内置插件页报 `loaded without registering ... via __ModuleLoader__.load`：客户端模块加载器缺失时显式报错，不再静默跳过注册。

## 1.0.21

- 状态卡调整：「服务地址」从页面底部移到「版本」下一行，只读展示（内置 / 自定义），底部不再重复。
