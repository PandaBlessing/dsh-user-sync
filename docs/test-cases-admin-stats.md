# 测试用例清单：管理后台上传/下载统计、包列表性能、技能包下载

> 对应设计：`docs/design-admin-stats-download.md`（v3）。
> 覆盖范围：统计埋点（客户端下载/上传）→ MySQL 同步 → 同步包管理页/首页/容量监控页/插件统计页展示 → 包列表分页 → 插件统计分页 → zip 下载 → 降级与边界。
> 类别：正常 / 临界 / 异常。执行结果记录在 `TESTREPORT.md`，本文件只列用例。

## A. 上传计数

| # | 前置 | 步骤 | 预期 | 类别 |
|---|---|---|---|---|
| TC-A01 | 账号已配对，本地有变更 | 客户端执行「上传用户配置」成功 | 该账号 `uploads +1`，`last_upload_at=now` | 正常 |
| TC-A02 | 同上 | 上传时网络中断 / 401 失败 | 次数不变 | 异常 |
| TC-A03 | 同步范围为 0 文件 | 上传（服务端拒绝空包 `E_EMPTY_PACKAGE`） | 次数不变，客户端提示空包原因 | 异常 |
| TC-A04 | 初始无 stats 字段的旧账号 | 首次上传成功 | 初始化 `uploads=1`，其余为 0，不报错 | 临界 |
| TC-A05 | 同一账号 | 连续快速上传 3 次（无并发丢失） | `uploads=30→+3`，3 次均计 | 临界 |
| TC-A06 | 两个不同账号 | 同时上传 | 各自计数互不影响 | 临界 |
| TC-A07 | 同步包超 quotaPackageBytes（10MB） | 上传 | 服务端拒绝超大包，计数不变，客户端提示原因 | 临界 |

## B. 下载计数

| # | 前置 | 步骤 | 预期 | 类别 |
|---|---|---|---|---|
| TC-B01 | 远端有包 | 客户端执行「从远端同步」成功 | `downloads +1`，`last_download_at=now` | 正常 |
| TC-B02 | 同上 | 后台「同步包管理」查看包（admin 路由） | `downloads` 不变 | 正常 |
| TC-B03 | 同上 | 旧客户端（<1.0.35，无 `x-dsh-sync-client` 头）同步 | `downloads` 不变（设计预期，发版说明） | 临界 |
| TC-B04 | 远端无包 | 客户端同步（404/空） | 次数不变 | 异常 |
| TC-B05 | 首次下载 | 初始化 `downloads=1` | 不报错 | 临界 |
| TC-B06 | 网关/代理转发 | 客户端请求经 nginx 转发 | 自定义头保留，计数生效 | 临界 |
| TC-B07 | 客户端只执行「检查更新」不下载 | 点检查 | downloads 不变（检查不拉包） | 临界 |
| TC-B08 | 下载中断后重试并成功 | 重试成功 1 次 | downloads 只 +1（按成功下载次数计） | 临界 |

## C. 统计同步进 MySQL（admin 后端）

| # | 前置 | 步骤 | 预期 | 类别 |
|---|---|---|---|---|
| TC-C01 | admin 服务启动 | 启动完成 | `sync_account_stats` 数据与 sync server `/v1/admin/usage` 一致 | 正常 |
| TC-C02 | 运行中 | 等待 ≥5 分钟 | 定时任务拉取并 upsert，数据更新 | 正常 |
| TC-C03 | 页面 | 点「刷新」 | 立即发起一次同步，返回后列表更新 | 正常 |
| TC-C04 | 统计已同步 | 连续两次同步相同数据 | `uploads/downloads` 不重复累加（覆盖为绝对值） | 临界 |
| TC-C05 | sync server 停止 | 等待定时/点刷新 | 同步失败不崩溃，保留上次数据，页面提示统计不可用 | 异常 |
| TC-C06 | 老账号数据无 stats | 首次同步 | 写入默认 0，不报错 | 临界 |
| TC-C07 | 账号在 server 侧被删除 | 下一次同步 | MySQL 旧行保留（不删除），页面显示最近值（策略：只增不删） | 临界 |
| TC-C08 | 并行触发（定时 + 手动） | 同时两次同步 | 无重复行、无死锁（upsert 幂等） | 临界 |
| TC-C09 | 表未迁移 | 首次启动 | 自动迁移建表成功；失败时启动日志明确报错 | 异常 |
| TC-C10 | 大量账号（1000+） | 同步 | 全量 upsert 完成且耗时可控，页面分页不卡 | 临界 |
