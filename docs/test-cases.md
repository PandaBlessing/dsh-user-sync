# 测试用例清单

> 本文件**只放用例，不放结果**。运行结果单独记录在 `docs/test-results/`（约定见 §2）。
> 设计依据：[design.md](design.md)。每条用例都必须能回溯到设计章节，回溯不到的用例视为无依据，评审时删除或补设计。

## 1. 约定

- **编号**：`<模块>-<两位序号>`，模块见各节标题。
- **级别**：`P0` 阻断发布；`P1` 影响体验。
- **方式**：`单测`（`node --test`，可在 CI 跑）；`手测`（需要真实 DSH 实例）；`演练`（两份 `DSH_HOME`）。
- **fixture**：统一由 `test/fixtures/` 提供，结构约定见其 [README](../test/fixtures/README.md)（`dsh-home/` + `user-home/` 两个根）。用例只引用路径，不在用例里临时造数据。
  - `fx-minimal/dsh-home`：`profiles/desktop/{package.json,cordis.patch.yml,cordis.yml,pnpm-workspace.yaml}` + `AGENTS.md` + `memories/MEMORY.md`
  - `fx-full`：在 `fx-minimal` 基础上加 `pnpm-lock.yaml`、`memories/USER.md`、`memories/projects/9f2c1a/TODOS.md`、`memories/daily/2026-10-23.md`、`sessions/--H-work-demo--/`、`storages/workspace.json`、`user-home/.agents/skills/{foo/SKILL.md,bar/main.js}`
  - `fx-crlf`：与 `fx-minimal` 内容相同但全部 CRLF 换行（`.gitattributes` 用 `* -text` 保护字节）
  - `fx-secret`：`sk-` 明文、`.credentials.yaml`、`memories/id_rsa`
  - `fx-v2`：原型脚本的 `schemaVersion: 2` 包（`manifest.json` + 两个文件，哈希为真实删 CR 后 SHA-256）
  - 符号链接不在仓库里预置，SCAN-07/08 在测试中用临时目录动态创建

## 2. 结果记录

- 结果目录：`docs/test-results/`，每次运行一个文件：`YYYY-MM-DD-<触发者>.md`。
- 文件内只写四列：`用例 ID`、`结果`（通过/失败/跳过）、`证据`（命令、日志路径、截图）、`备注`。
- **不复制用例描述**，靠 ID 回链本文件。
- 失败用例在结果文件里标 `失败` 并写明实际输出与预期差在哪；修复后再跑一次，追加一行 `重跑`，不覆盖旧结果。
- 清单本身不写任何「通过/失败」状态，避免清单随每次运行腐化。
