# 设置同步面板 · UI 测试用例清单

> 范围：面板（client）所有按钮、弹窗、状态文案与对应行为。
> 每条用例：**操作 → 预期 UI → 预期接口/副作用**。UI 必须与判定结果一致（不能出现「动作是拉取、文案说上传」）。

| # | 操作 | 预期 UI | 预期接口/副作用 |
|---|---|---|---|
| UI-01 | 打开面板 | 状态行：主目录 / Profile / 账号 / 版本 / 服务地址 / 接口 / 扫描 | `GET /status` 成功 |
| UI-02 | 未配对账号 | 账号行显示「未登录官方账号」 | — |
| UI-03 | 已配对 | 账号行「已配对 · 5e15a3」 | — |

| UI-05 | 扫描为空 | 扫描行「尚未扫描」 | — |

## E. 从远端同步

| # | 操作 | 预期 UI | 预期接口/副作用 |
|---|---|---|---|
| UI-40 | 点「从远端同步」，判定 pull（远端更新） | **只弹覆盖确认弹窗**（远端包名+时间+将覆盖 N 个文件），不弹「检查完成」 | `GET /check` → `apply` |
| UI-41 | 判定 push（本地更新） | 弹窗「检查完成：本地有更新，可上传到远端（或用『上传用户配置』覆盖远端）」 | `GET /check`，不触发 apply |

| UI-45 | 点取消 | 不改本地文件 | — |
| UI-46 | 同步中 | 按钮禁用，文案「同步中…」 | — |
| UI-47 | 同步失败 | 弹窗「同步失败」+ 原因 | apply 返回 error |

| UI-49 | 检查接口失败 | 弹窗「检查失败」+ 原因 | notice error |

## J. 判定文案对照（必须与 action 一致）

| action | 弹窗 | 文案 |
|---|---|---|
| `pull` / `confirm` | 覆盖确认弹窗 | 「远端包 <name>（<createdAt>），将覆盖本机 N 个文件」 |
| `push` | 检查完成 | 「本地有更新，可上传到远端（或用『上传用户配置』覆盖远端）」 |
| `skip` | 检查完成 | 「已是最新」 |
| `upload` 成功 | 上传完成 | 「包名 / 文件数」 |
| `upload` 失败 | 上传失败 | 原因（code） |
